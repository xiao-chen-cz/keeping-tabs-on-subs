# Keeping Tabs on Subs

Mobile-first subscription tracker (Next.js, TypeScript, Tailwind). See `CLAUDE.md` and `specs/` for scope and logic.

## Commands

Requires Node and pnpm.

```bash
pnpm install     # install dependencies
pnpm dev         # run locally at http://localhost:3000
pnpm test        # run unit tests once (pnpm test:watch to watch)
pnpm lint        # lint
pnpm build       # production build
```
